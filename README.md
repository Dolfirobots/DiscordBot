The **Dolfirobots Network** Discord bot is a manager Discord bot
with a lot of functions.

I don't have the time to make newer updates. Please be patient!

---

## ✨ Features
- ✨ Cool join message
- ✨ Cool leave message
- 💾 SQLite support
- 🎟️ Ticket system
- 🤣 /meme command
- 📗 /help command
- 🟢 Server stats in profile

## ⏳ Planned
- 🟢 Server status in channel
- ⚠️ Report message
- 🏃‍➡️ Make it faster
- 😊 More cool commands and features
- 💬 Per user language
  - German
  - English
