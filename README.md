The **Dolfirobots Network** Discord bot is a manager Discord bot
with a lot of functions.

---

## ✨ Features
- ✨ Cool join message
- ✨ Cool leave message
- 2️⃣ Dual mode for 2 bot systems:
  - Ticket Bot
  - Main Bot

## ⏳ Planned
- 💾 SQLite support
- 🎟️ Ticket system
  - ✨ AI support (Local AI)
- ⚠️ Report message
- 🤣 /meme command
- 📗 /help command
